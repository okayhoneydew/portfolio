# Shaun Portfolio V1

This is intentionally tiny: one HTML file and one CSS file.

## Recommended hosting: GitHub Pages

1. Create a new GitHub repository, for example `shaun-portfolio`.
2. Upload `index.html` and `styles.css` to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, branch **main**, folder **/ (root)**.
5. Save. GitHub will publish the site at a `github.io` URL.
6. Add a custom domain later if you want.

## Before publishing

Replace the four `href="#"` links in the Contact section with your actual email, LinkedIn, resume, and GitHub links.

## V1 rule

Do not add a framework, CMS, database, backend, animation library, or analytics stack yet. If the content is accurate and the page is live, V1 is done.
